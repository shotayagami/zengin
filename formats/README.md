# 業務のレコード・フォーマット

全銀協「全銀協パーソナル・コンピュータ用標準通信プロトコル (ベーシック手順) 〔別冊〕適用業務およびレコード・フォーマット」
(AP-Ⅰ-13、13 版、令和 8 年 10 月) の「Ⅱ 全銀協制定レコード・フォーマット」の表を、業務ごとに書き写したもの。
ファイル名は別冊の番号 (1 振込入金通知・4 給与振込・8 総合振込は `src/record.rs` に直接書いてあるので、ここにはない)。

- `records`: ヘッダー・データ・トレーラ・エンドの項目 (名前、別冊の項目名 `ja`、属性 `k` = N 数字 / C 文字、桁数 `len`、要点 `note`)。
  データ・レコードの様式が複数あるときは `variant` と、その選び方 `variant_rule`。
- `notes`: 実装に要ること (トレーラの集計、コードの一覧、別冊の誤植と思われる箇所など)。別冊に明記がなく読みで決めたものは、そう書いてある。
- `problems`: 書き写しで解決できなかった点 (別冊の記載どうしの食い違いなど)。

`python scripts/gen-formats.py` で `src/formats.rs` を作る。各レコードの桁数の合計がレコード長になること、項目名が重ならないことを確かめる。
データ・レコードの様式の選び方とトレーラの集計は、`scripts/gen-formats.py` の表 (`SEL`、`CHECKS`) に書く。

別冊の文章や図表はここに含めない。項目の並びと桁数 (取り決めそのもの) と、要点の言い換えだけを書く。
書き写しは、別冊から抽出した文字と、必要に応じて紙面の画像を見て行った。誤りに気づいたら、別冊の頁を添えて知らせてほしい。
